# Learning-Focused System Prompts for New stibodx Team Member

## Updated Context: Educational Assistant for CUE Content Store Learning

The system has been enhanced to serve as an **educational assistant** for a new stibodx team member learning the CUE Content Store Publication Design Guidelines.

### Key Changes Made

#### 1. **Educational Response Framework**

The response system now prioritizes:

- **Detailed, educational explanations** that build deep understanding
- **Practical examples, code snippets, XML configurations** when helpful
- **Step-by-step breakdowns** of complex concepts
- **Multiple perspectives** and approaches ("You can achieve this in two ways...")
- **Proactive learning support** with related topics and follow-ups

#### 2. **Learning-Oriented Routing**

Enhanced routing logic that favors documentation retrieval for:

- ✅ **Example requests**: "Show me an example of XML configuration"
- ✅ **Deep explanations**: "Help me understand how section pages work"
- ✅ **Learning queries**: "Explain in detail how guidelines work"
- ✅ **Implementation help**: "What workflows should I know about?"

#### 3. **Enhanced Response Guidelines**

The assistant now provides:

- **XML configuration snippets** with explanations
- **Step-by-step workflow examples**
- **Before/after scenarios** showing different approaches
- **Conceptual diagrams** described in text
- **Comparison tables** of different options
- **Common gotchas** and troubleshooting tips
- **Integration examples** showing how features work together

### Example Response Formats

When you ask for help, the system will now provide:

```xml
<!-- Example CUE Content Store configuration -->
<publication>
  <section name="news">
    <content-items>
      <!-- Detailed explanation of each element -->
    </content-items>
  </section>
</publication>
```

**Plus explanations of:**

- Why this structure is used
- How it fits into broader CUE workflows
- Alternative approaches you might consider
- Common issues to watch for

### Testing Results

✅ **Learning-Focused Questions** properly routed to 'retrieve':

- "Can you show me an example of a CUE Content Store XML configuration?"
- "Help me understand how section pages work in CUE Content Store"
- "What are some examples of content item workflows I should know about?"
- "Explain in detail how the publication design guidelines work"

✅ **General Questions** still routed to 'direct':

- "Hello, how are you?"
- "Tell me about stibodx as a company"
